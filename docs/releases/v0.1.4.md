# AniStream v0.1.4

AniStream v0.1.4 is the coordinated Windows and macOS desktop release built from one validated
`main` commit. It delivers the approved Home/Profile redesign, dependable resume behavior, smoother
media surfaces, and provider-aware recovery messages.

## Highlights

- Unified Anime and Manga home navigation with Trending, Continue, For You, and Latest Updates rails.
- Unified search with debounced suggestions, type filters, independent pagination, and stale-request
  protection.
- Functional launch/Profile readiness screen with provider checks and friendly recovery guidance.
- Correct Continue playback targets from AniList progress and local checkpoints; no forced Episode 1
  fallback and no redundant playback-position banner.
- Rounded AniList-backed season selection, auto-hidden player/reader controls, and in-app fullscreen
  for anime playback and manga reading.
- Scoped refresh buttons, smoother Windows motion, hidden outer scrollbar, Plus Jakarta Sans, and
  refreshed profile artwork transitions.
- Supplied Ani branding in the navbar, with native multi-resolution Windows ICO and macOS ICNS app
  icons for packaged builds.
- Cross-platform package gates for preload safety, ASAR freshness, native SQLite binaries, and the
  Windows installer lifecycle.

## Downloads

- `AniStream-0.1.4-arm64.dmg` — Apple Silicon macOS 12+
- `AniStream Setup 0.1.4.exe` — Windows x64

Both packages are unsigned. macOS may require Control-click → Open on first launch, and Windows
SmartScreen may show an unsigned-app warning. Signing and notarization are not configured yet.

## Updates

Installed supported builds check the public GitHub release endpoint at startup. You can also open
**Profile → App updates → Check for updates**. The checker reports a release only when the matching
installer asset is present and never downloads or replaces the app automatically.

## Verification

The release workflow runs native branding validation, strict TypeScript, lint, formatting, Vitest,
production build, product contract, AniList OAuth, packaged ASAR/preload, npm audit, and Windows
installer lifecycle checks.
The macOS runner additionally verifies the Apple Silicon bundle and mounted DMG. Native signing,
notarization, and interactive macOS testing remain separate release steps.
