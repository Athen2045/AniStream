# AniStream v0.1.3

AniStream v0.1.3 is a maintenance and release-readiness update focused on safer startup, smoother
catalog behavior, and cleaner cross-platform packaging.

## Highlights

- Added guarded Electron startup so the window opens only after the database and IPC handlers are
  ready.
- Added a clear startup failure path instead of leaving a half-open shell.
- Made AniList logout recover gracefully if secure credential deletion fails.
- Added hero artwork fallback from banner to cover to a stable placeholder.
- Kept latest-update cards visible while refreshing instead of replacing them with skeletons.
- Standardized motion timing and reduced layout reflow during rail hover interactions.
- Scoped GitHub release write permissions to tag-only release jobs.
- Updated transitive dependencies; npm audit now reports zero vulnerabilities.
- Added maintainer guidance for clean installs, security checks, and release verification.

## Downloads

Release workflows produce these unsigned artifacts:

- `AniStream-0.1.3-arm64.dmg` for Apple Silicon macOS 12+
- `AniStream Setup 0.1.3.exe` for Windows x64

The macOS DMG and Windows installer are unsigned. macOS may require Control-click → Open on first
launch, and Windows SmartScreen may display an unsigned-app warning. Signing and notarization remain
open release work.

## Known limitations

- Media availability depends on external providers and can change without notice.
- AniList connection requires browser approval but does not require users to create a Developer API
  client or provide a secret.
- Apple signing/notarization and Windows Authenticode signing are not configured yet.
- The macOS artifact must be built on a macOS runner; Windows development machines should use the
  GitHub Actions macOS workflow for the DMG.

## Verification

The release should pass typecheck, lint, formatting, Vitest, production build, product-slice,
AniList OAuth, packaged-preload, and npm audit checks before publishing.
