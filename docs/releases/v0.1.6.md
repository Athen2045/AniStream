# AniStream v0.1.6

Ahh, my bad — this release fixes an issue where new users could get stuck on the AniList loading
screen before they could access the app.

## Highlights

- Guest installs can continue into the app shell when public AniList discovery is temporarily
  unavailable; the catalog remains retryable from the app.
- Local startup checks remain enforced so incomplete local data is still reported clearly.
- Removed retired recommendation preview code, unused IPC channels, obsolete provider contracts,
  and unreferenced legacy Lato font assets.
- Kept the Ani navbar branding, native Windows/macOS icons, unified discovery, playback, manga reader,
  profile, and local progress features from the previous release.

## Downloads

- `AniStream-0.1.6-arm64.dmg` — Apple Silicon macOS 12+
- `AniStream Setup 0.1.6.exe` — Windows x64

Both packages are unsigned. macOS may require Control-click → Open on first launch, and Windows
SmartScreen may show an unsigned-app warning. Signing and notarization are not configured yet.

## Updates

Installed supported builds check the public GitHub release endpoint at startup. You can also open
**Profile → App updates → Check for updates**. The checker reports a release only when the matching
installer asset is present and never downloads or replaces the app automatically.

## Verification

The release workflow runs native branding validation, strict TypeScript, lint, formatting, Vitest,
production build, product contract, AniList OAuth, packaged ASAR/preload, npm audit, and Windows
installer lifecycle checks. The macOS runner additionally verifies the Apple Silicon bundle and
mounted DMG. Native signing, notarization, and interactive macOS testing remain separate release
steps.
