# AniStream v0.1.7

This maintenance release fixes some minor bugs and refines the interface across the shared Windows
and macOS app.

## Highlights

- Improved the navbar account controls for guest and signed-in users.
- Added a dedicated Settings view for local data, backups, and app updates.
- Refined notification icons and account-menu keyboard behavior.
- Fixed the signed-in profile image alignment and removed the obsolete Profile hero menu.
- Included minor playback, episode-list, personalization, and provider error-handling fixes.

## Downloads

- `AniStream-0.1.7-arm64.dmg` — Apple Silicon macOS 12+
- `AniStream Setup 0.1.7.exe` — Windows x64

Both packages are unsigned. macOS may require Control-click → Open on first launch, and Windows
SmartScreen may show an unsigned-app warning. Signing and notarization are not configured yet CAUSE I AM BROKE.

## Updates

Installed supported builds check the public GitHub release endpoint at startup. You can also open
**Account menu → Settings → App updates → Check for updates**. The checker reports a release only
when the matching installer asset is present and never downloads or replaces the app automatically.

## Verification

The release workflow runs native branding validation, strict TypeScript, lint, formatting, Vitest,
production build, product contract, AniList OAuth, packaged ASAR/preload, npm audit, and Windows
installer lifecycle checks. The macOS runner additionally verifies the Apple Silicon bundle and
mounted DMG. Native signing, notarization, and interactive macOS testing remain separate release
steps.
